# Стренг — Линейная алгебра и её применения

Г. Стренг. «Линейная алгебра и её применения» (Gilbert Strang, Linear Algebra and Its Applications). Пер. с англ. — М.: Мир, 1980.

Источник: `Streng_G_-_Lineynaya_algebra_i_ee_primenenia-Mir_1980.djvu`, `download/ya_disk/Books/Math/АнГем/` (DjVu; страницы файла = печатная страница + 5, т.к. в начале файла идут предметный указатель (стр. файла 1-9) и решения задач — сверено по оглавлению и рендеру, не по `djvutxt`).

Прикладной курс линейной алгебры (M.I.T.), акцент на вычислительные методы и приложения (в отличие от [[../beklemishev/README|Беклемишева]] — строгой академической аналитической геометрии). Минимальное пересечение с уже готовыми материалами.
