**24.26, 1)-2) (р).** *Пусть $\lambda_1,\ldots,\lambda_n$ — характеристические числа линейного преобразования $\varphi$ в $n$-мерном линейном пространстве. Чему равны характеристические числа (с учетом кратностей) преобразования: 1) $\varphi^2$; 2) $\varphi^m$ ($m$ — натуральное число)?* (см. [[sbz_g09_s24_invariantnye_podprostranstva#24.26|§24, задача 24.26, пп. 1–2]])

Пусть $A$ — матрица преобразования $\varphi$ в некотором базисе и
$$\det(A-\lambda E)=(\lambda_1-\lambda)\ldots(\lambda_n-\lambda).$$
1) Заменив $\lambda$ на $-\lambda$, имеем также
$$\det(A+\lambda E)=(\lambda_1+\lambda)\ldots(\lambda_n+\lambda).$$
Перемножив эти равенства, получим
$$\det(A^2-\lambda^2E)=(\lambda_1^2-\lambda^2)\ldots(\lambda_n^2-\lambda^2),$$
или
$$\det(A^2-tE)=(\lambda_1^2-t)\ldots(\lambda_n^2-t),$$
где $t=\lambda^2$.

2) В разложении характеристического многочлена заменим $\lambda$ на $\lambda\varepsilon^k$ ($k=0,\ldots,m-1$), где $\varepsilon=e^{2\pi i/m}$ ($\varepsilon^m=1$):
$$\det(A-\lambda E)=(\lambda_1-\lambda)\ldots(\lambda_n-\lambda),$$
$$\det(A-\lambda\varepsilon E)=(\lambda_1-\lambda\varepsilon)\ldots(\lambda_n-\lambda\varepsilon),$$
$$\ldots\ldots\ldots\ldots\ldots\ldots\ldots\ldots\ldots\ldots\ldots\ldots$$
$$\det(A-\lambda\varepsilon^{m-1}E)=(\lambda_1-\lambda\varepsilon^{m-1})\ldots(\lambda_n-\lambda\varepsilon^{m-1}).$$
Поскольку матрицы $A-\lambda\varepsilon^kE$ ($k=0,\ldots,m-1$) перестановочные, перемножив равенства почленно, получим
$$\det(A^m-\lambda^mE)=(\lambda_1^m-\lambda^m)\ldots(\lambda_n^m-\lambda^m),$$
или, положив $\lambda^m=t$, требуемое
$$\det(A^m-tE)=(\lambda_1^m-t)\ldots(\lambda_n^m-t).$$
Здесь использовано разложение $a^m-\lambda^m=(a-\lambda)(a-\lambda\varepsilon)\ldots(a-\lambda\varepsilon^{m-1})$. Чтобы получить его, достаточно заметить, что многочлен $a^m-\lambda^m$ имеет корни $a,a\varepsilon,\ldots,a\varepsilon^{m-1}$.

**24.127, 12) (р).** *Привести к жордановой форме матрицу $A_{283}$.* (см. [[sbz_g09_s24_invariantnye_podprostranstva#24.127|§24, задача 24.127, п. 12]])

Характеристическое уравнение $(\lambda+1)^3=0$.
$$B=A_{283}+E=\begin{Vmatrix}3&5&1\\-1&-2&0\\-2&-3&-1\end{Vmatrix}.$$
$\operatorname{Rg}B=2$. Собственное подпространство одномерно. Находим его базисный вектор: $h_1=\|-2\ 1\ 1\|^T$. Составляем систему уравнений для первого присоединенного вектора:
$$\left\|\begin{array}{ccc|c}3&5&1&-2\\-1&-2&0&1\\-2&-3&-1&1\end{array}\right\|.$$
Ее решение $h_2=\|1\ -1\ 0\|^T$. Система уравнений для второго присоединенного
$$\left\|\begin{array}{ccc|c}3&5&1&1\\-1&-2&0&-1\\-2&-3&-1&0\end{array}\right\|.$$
Из нее находим $h_3=\|1\ 0\ 2\|^T$. Итак, $A'=J_3(-1)$. Матрица перехода к жорданову базису
$$\begin{Vmatrix}-2&1&1\\1&-1&0\\1&0&2\end{Vmatrix}.$$

**24.127, 15) (р).** *Привести к жордановой форме матрицу $A_{465}$.* (см. [[sbz_g09_s24_invariantnye_podprostranstva#24.127|§24, задача 24.127, п. 15]])

Характеристическое уравнение $\lambda^3(\lambda-2)=0$. Найдем собственное подпространство для $\lambda=0$. Матрица $A_{465}$ элементарными преобразованиями строк приводится к виду
$$\begin{Vmatrix}1&0&0&0\\0&1&-1&1\end{Vmatrix}.$$
Поэтому собственное подпространство двумерное. Так как корневое пространство трехмерное, должен быть один присоединенный вектор. Найдем его. Произвольный собственный вектор можно написать как $h=\alpha\|0\ 1\ 1\ 0\|^T+\beta\|0\ 0\ 1\ 1\|^T$. Присоединенный вектор существует у того вектора, для которого совместна система уравнений с матрицей
$$\left\|\begin{array}{cccc|c}1&1&-1&1&0\\1&-1&1&-1&\alpha\\-3&-1&1&-1&\alpha+\beta\\-3&1&-1&1&\beta\end{array}\right\|.$$
Условие совместности $\beta=-2\alpha$, и можно взять $\alpha=2$, $\beta=-4$, что соответствует собственному вектору $h_1=\|0\ 2\ -2\ -4\|^T$. Находим частное решение системы для $\alpha=2$, $\beta=-4$. Это и есть присоединенный к $h_1$ вектор $h_2=\|1\ 0\ 1\ 0\|^T$. **24.148 (р).** *Пусть $\varphi$ и $\psi$ — линейные преобразования пространства $\mathcal{L}$, причем $\varphi$ взаимно однозначно. Найдите такое $\varepsilon>0$, что для любого $\delta\in(-\varepsilon,\varepsilon)$ линейное преобразование $\varphi+\delta\psi$ взаимно однозначно.* (см. [[sbz_g09_s24_invariantnye_podprostranstva#24.148|§24, задача 24.148]])

При $\delta=0$ преобразование взаимно однозначно. При $\delta\neq0$ его можно представить в виде $\varphi+\delta\psi=\delta\varphi(\delta^{-1}\iota+\varphi^{-1}\psi)$. Преобразование будет взаимно однозначным тогда и только тогда, когда взаимно однозначен второй сомножитель. Таким образом, мы ищем те $\delta$, для которых $\det(\varphi^{-1}\psi+\delta^{-1}\iota)\neq0$. Для этого достаточно, чтобы $|\delta^{-1}|$ был больше максимального из модулей собственных значений преобразования $\varphi^{-1}\psi$. Пусть это число равно $\rho$. Тогда можно положить $\varepsilon=\rho^{-1}$.
