# beran_uporyadochennye: Упорядоченные множества

Беран Л. «Упорядоченные множества». Перевод с чешского В. Н. Салия; под редакцией Л. А. Скорнякова. М.: Наука, Главная редакция физико-математической литературы, 1981. 64 с. Серия «Популярные лекции по математике», выпуск 55.

Источник: `{books}/Math/АнГем/[Beran_L.]_Uporyadochennuee_mnozhestva(libcats.org).djvu` (DjVu; номер страницы файла опережает печатный номер на 1, `file_page_offset = 1`).

Популярное введение в теорию частично упорядоченных множеств и решеток: рассматриваются точные верхние и нижние грани, алгебраические свойства решеточных операций, а также модулярные и дистрибутивные решетки. Книга рассчитана на старшеклассников и студентов младших курсов и требует лишь знакомства с основами теории множеств.
