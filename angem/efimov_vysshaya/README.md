# Ефимов — Высшая геометрия

Н. В. Ефимов. «Высшая геометрия». Издание пятое. — М.: Наука, 1971. — 576 с.

Источник: `Efimov_Vysshaya_geometria_5-e_izd_1971.pdf`, `download/ya_disk/Books/Math/АнГем/геом_доп/` (PDF; номер страницы файла = печатная страница, сверено по рендеру).

Основания геометрии (система Гильберта), неевклидова геометрия Лобачевского и Римана, проективная геометрия, пространство Минковского. Пересечение с уже готовыми материалами ([[../beklemishev/README|Беклемишев]], [[../gusyatnikov/README|Гусятников]]) практически отсутствует — другой, более теоретический раздел, продолжающий базовый курс аналитической геометрии.

`assets/` — изображения и сканы к этому разделу.
