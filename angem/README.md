Заметки по аналитической геометрии — параллельно с [[../plane_equation|уравнением плоскости]] из основного раздела `linalg`.

## Конвенция разбора книги

Один файл — один параграф (§) книги, с сохранением привязки к страницам оригинала.

**Имя файла:** `{автор}_g{глава:02d}_s{параграф:02d}_{слаг}.md`
Пример: `bekl_g01_s01_vektory.md` — Беклемишев, глава 1, §1, «Векторы».

**Границы страниц внутри файла:** на каждом переходе на новую страницу книги — маркер:
```
---
**стр. 6**
---
```

**Ассеты (сканы, рисунки):** только в `assets/`, никогда рядом с `.md`. Подпапка на файл, имя = имя md-файла без расширения; внутри — `p{страница}-fig{№}.ext`.
```
assets/bekl_g01_s01_vektory/p06-fig1.png
```
Ссылка из текста — сразу после маркера нужной страницы:
`![Рис. 1](assets/bekl_g01_s01_vektory/p06-fig1.png)`

**Источник в формате DjVu:** встроенный текстовый слой (`djvutxt`) часто «шумит» OCR-ошибками (спутанные кириллические литеры, съехавшие индексы) — для транскрипции текста и рисунков страницы рендерятся в изображение и читаются вручную, а не через `djvutxt`. Конвейер: `ddjvu -format=ppm -page=N file.djvu out.ppm`, затем `PIL.Image.open(...).save(..., "PNG")` (конвертация + при желании ресайз для читаемости). Пакет `djvulibre-bin` (даёт `djvutxt`/`ddjvu`/`djvudump`).
