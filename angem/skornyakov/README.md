# skornyakov_slu: Системы линейных уравнений

Автор: Скорняков Л. А. «Системы линейных уравнений». М.: Наука, Главная редакция физико-математической литературы, 1986. 64 с. (Популярные лекции по математике, выпуск 59). Рецензент: Д. В. Беклемишев.

Источник: `{books}/Math/АнГем/[Skornyakov_L._A.]_Sistemue_lineinueh_uravneny(libcats.org).djvu` (формат DjVu, `file_page_offset = 1`: печатная страница N находится на скане N+1).

Краткая характеристика книги: брошюра из серии «Популярные лекции по математике» об системах линейных уравнений. Изложение опирается только на элементарные преобразования матриц: вводятся строки, матрицы системы и расширенная матрица, метод Гаусса, ранг, теорема Кронекера–Капелли и фундаментальные системы решений. Рассчитана на широкий круг читателей, включая старшеклассников; в книге есть ответы и решения задач.

`assets/` — изображения и сканы к этому разделу.
