# прасолов_шарыгин_зачади_по_стереометрии: разведка

**Автор/издание:** В. В. Прасолов, И. Ф. Шарыгин / Москва, «Наука», Главная редакция физико-математической литературы
**Год:** 1989
**Объём:** 288 стр., 16 глав + вводная часть

## Профиль

**Уровень:** школьный олимпиадный / кружковой (серия «Библиотека математического кружка», вып. 19). Предназначен для учащихся старших классов, преподавателей, руководителей кружков и студентов педагогических институтов.

**Широта покрытия:** охватывает классическую стереометрию от прямых и плоскостей до инверсии и стереографической проекции. 16 тематических глав плюс вводный раздел «Знакомство со стереометрией». В каждой главе 5–6 параграфов; есть отдельные главы для неравенств, экстремумов, построений, методов решения (крайний, Дирихле), центра масс, барицентрических координат.

**Глубина (по вступительным материалам):** сборник содержит около 560 задач с подробными решениями и около 60 задач для самостоятельной работы. Большинство задач близко к школьной программе, но есть и повышенной трудности. Материал систематизирован по циклам, связанным общей идеей решения, с возрастанием сложности внутри цикла. Авторы ожидают владения планиметрией (даются ссылки на соответствующие задачники Прасолова и Шарыгина) и не повторяют известные планиметрические доказательства. Структура каждой главы: краткие теоретические установки/формулы → разобранные задачи → задачи для самостоятельного решения с ответами. Включены олимпиадные темы: центр масс, инверсия, целочисленные решётки, разрезания и склейки.
