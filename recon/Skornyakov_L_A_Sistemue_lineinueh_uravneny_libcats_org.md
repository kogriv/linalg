# Skornyakov_L_A_Sistemue_lineinueh_uravneny_libcats_org: разведка

**Автор/издание:** Л. А. Скорняков (Лев Анатольевич Скорняков), издательство «Наука», Главная редакция физико-математической литературы, Москва; серия «Популярные лекции по математике», выпуск 59  
**Год:** 1986  
**Объём:** 64 стр., 6 параграфов (§1–§6) + предисловие, ответы, решения, предметный указатель

## Профиль

**Уровень:** между старшей школой и вузовским базовым; брошюра из популярной серии, но с формальными определениями, теоремами и доказательствами. Аннотация ориентирует на широкий круг читателей, включая старшеклассников; предисловие указывает происхождение материала из курса для студентов кафедры структурной лингвистики МГУ.

**Широта покрытия:** узкая тема — системы линейных уравнений. Шесть параграфов: от определений и эквивалентности систем через матрицы и элементарные преобразования к методу решения, рангу, теореме о главных неизвестных и фундаментальным системам решений. Дополнительно: упражнения, блок «Ответы» (стр. 53), «Решения» (стр. 57), предметный указатель (стр. 62).

**Глубина (по вступительным материалам):** аннотация обещает «исчерпывающее изложение» при опоре только на элементарные преобразования матриц — без аппарата линейных пространств. Предисловие: метод полной математической индукции формально не используется (местами «и т. д.»), но читатель может довести изложение до строгого уровня; для углубления рекомендуется учебник «Элементы алгебры» (1980). По тексту §1: аккуратные определения, теорема 1.1 с доказательством, задачи с прикладными формулировками; упражнения служат для самопроверки. Компактная брошюра (~3,4 уч.-изд. л.), тираж 100 000.
